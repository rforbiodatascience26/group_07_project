# R for BioData Science - Group 7 - Project

### Downloading the Data

The data used in this project is from [cBioPortal (Study: tmb_mskcc_2018)](https://www.cbioportal.org/study/clinicalData?id=tmb_mskcc_2018).

After cloning the repository, the raw data needs to be downloaded in order to run the project. To do so:

1. Download all clinical and genomic data for this study.
2. Create a `data` folder in your project root folder.
3. Create a `_raw` folder inside the `data` folder.
4. Place the following files inside the `_raw` folder:
   - `data_clinical_patient.txt`
   - `data_clinical_sample.txt`
   - `data_gene_panel_matrix.txt`
   - `data_mutations.txt`
   - `data_sv.txt`
