Analysis of the caracteristics of the mutations

The aim of this part of the analysis is to look into: - where in the genome the mutations occur - effect of mutation and cancer type or survival - the link between the position of the mutation and the cancer types - whether there are differences between location based on sex - whether there are differences in muation location and survival of patients

Looking for correlation between the length of mutations in patients and their survival

From the joint table, patients are filtered to keep only those who died. Then mutation length is summarized, as patients often have multiple mutations. Grouping here doesn’t duplicate patients as each patient has only one number of mutations, cancer type and os_month value

patient_mutation_summary <- clinical_mutation |> 
                              select(c(patient_id, length_mutation, status, total_mutations, os_months, cancer_type))|> 
                              filter(status == "DECEASED") |> 
                              group_by(patient_id, os_months, total_mutations, cancer_type) |> 
                              summarize(mean_length_mutation = mean(length_mutation),
                                        max_length_mutation = max(length_mutation))
`summarise()` has grouped output by 'patient_id', 'os_months',
'total_mutations'. You can override using the `.groups` argument.
patient_mutation_nested <- patient_mutation_summary |> 
                              group_by(cancer_type) |> 
                              nest() |> 
                              ungroup() |> 
                              mutate(model_object = map(.x= data,
                                                        .f = ~lm(formula = os_months ~ mean_length_mutation,
                                                                 data = .x)))
patient_mutation_tidy <- patient_mutation_nested |>
                          mutate(model_object_tidy = map(.x = model_object,
                                                         .f = ~tidy(.x, 
                                                                    conf.int = TRUE,
                                                                    conf.level = 0.95))) |> 
                          unnest(model_object_tidy)

p_mean <- patient_mutation_summary |> 
            filter(cancer_type == "Renal Cell Carcinoma") |> 
            ggplot(aes(x = mean_length_mutation,
                       y = os_months))+
            geom_point(alpha = 0.5)+
            geom_smooth(method = "lm")+
            labs(x = "Average length of mutation",
                 y = "Survival (months)",
                 title = "Survival as a function of average mutation length in patients with Renal Cell Carcinoma")+
            theme(plot.title = element_text(size = 8))

From this plot, we can see that the correlation is not very pronounced. What can be observed is that mutations are generally SNPs (length of 1).
